확인일: 2026-09-30. 아직 실제 코스 파일을 수집하거나 서비스 목록에 추가하지 않았다.

|---|---|---|
| 한국관광공사 두루누비 정보 서비스 | 공공데이터포털에 코리아둘레길 284개 코스 GPX 정보, 무료, 이용허락범위 제한 없음으로 안내. 개발 자동승인/운영 심의승인. 인증키 필요 | 우선 후보, 키 발급 후 API와 GPX 실제 응답 검증 필요 |

## 편입 절차

1. 공급원별 이용 조건·원본 주소·확인일 저장. API 키는 로컬 환경변수만 사용, 앱/웹 번들에 포함하지 않음.
2. 소량 파일 수집 후 XML/좌표/대한민국 영역/중복/비정상 점프 검사. 다중 구간 유지.
3. 원본 GPX와 웹 미리보기 좌표를 분리. 이름·지역·거리·제공기관·갱신일을 공통 카탈로그에 추가.
4. 웹은 동선 미리보기, 앱은 GPX 다운로드. 코스가 등록되어도 해당 지역 배경지도까지 오프라인 준비됐다고 표시하지 않음.
5. 현재 단일 서울숲 패키지 저장소를 복수 경로 저장소로 확장하고 딥링크도 코스 ID별 처리.
6. 추천 순위/사용량을 수집된 파일 개수나 출처로 임의 생성하지 않음. 원본의 활동 분류와 자체 데이트 추천 태그를 구분.

무료 API도 계정·활용신청은 필요하다. 기존 외부 계정 없는 방향을 유지하려면 별도로 재배포 허락이 명확한 공개 파일 공급원을 추가 확보해야 한다.
