# 플랫폼별 현장 검증

완료 체크는 실제 수행한 사람/기기/OS/빌드/날짜/결과를 STATUS.md에 기록한 뒤에만 한다. 아직 수행하지 않은 항목은 미검증이다.

## iPhone 설치 준비

1. USB로 iPhone을 Mac에 연결하고 잠금을 해제한다. iPhone의 Mac 신뢰 절차를 완료한다.
2. `apps/mobile/ios/app.xcworkspace`를 Xcode에서 연다. 프로젝트의 `app` 타깃 → Signing & Capabilities에서 본인의 Team을 선택한다. Apple 계정 로그인·서명 설정은 본인 계정으로 수행한다.
3. 실행 대상으로 연결된 iPhone을 선택한다. 개발자 모드를 요구하면 기기에서 안내를 따른다.
4. Product → Scheme → Edit Scheme → Run의 Build Configuration을 Release로 선택하고 실행한다. 시뮬레이터용 `.app` 파일은 실기기에 설치할 수 없다.
5. 프로젝트 루트에서 `python3 scripts/serve-data.py --host 0.0.0.0`을 실행한다. 같은 Wi-Fi의 iPhone 앱에 `http://Mac의-LAN-IP:8787`을 입력한다. 앱에서 로컬 네트워크 접근을 요청하면 허용한다.
6. 아래 현장 검증을 수행한다. 계정·인증서·프로비저닝 파일은 저장소에 추가하지 않는다.

현재 로컬 생성 프로젝트는 HTTP 개발 서버 허용 설정이다. `prebuild`로 다시 생성할 때는 `ALLOW_LOCAL_HTTP=1 ./scripts/dev.sh prebuild --platform ios`를 사용한다.

## iPhone 우선

1. 개발자 모드, Mac 신뢰, Xcode 서명 설정 후 Release 앱 설치.
2. 로컬 서버에서 581KiB 패키지 다운로드. 지도·한글 지명·주황색 GPX 표시 확인.
3. 현재 위치 허용. 실외에서 정확도와 갱신 시각 확인.
4. Wi-Fi와 셀룰러를 모두 끈다(비행기 모드에서도 Wi-Fi가 남아 있지 않은지 확인). Mac 데이터 서버와 Metro도 종료한다.
5. 앱을 강제 종료 후 다시 연다. 지도 이동·확대·축소, 한글 지명과 경로가 정상인지 확인한다.
6. 실외에서 이동하며 GPS가 갱신되는지 확인. 서울숲 밖이라면 ‘영역 밖’ 표시가 정상이며 근처 배경지도는 제공되지 않는다.
7. 위치 권한 거부, 위치 서비스 비활성화, 대략적 위치만 허용한 경우를 확인한다.
8. 백그라운드로 이동 후 복귀: 오래된 위치를 최신처럼 표시하지 않고 다시 수신해야 한다.
9. 저장 데이터 삭제 후 오프라인 재실행: 미저장 상태. 다시 인터넷에 연결해 다운로드하면 복구해야 한다.

## Android

2026-09-30 사용자 요청으로 추가 Android 테스트는 보류한다. 재개 시 동일 시나리오를 ARM 에뮬레이터에서 진행한다. `10.0.2.2:8787`은 호스트 Mac 서버다. 위치 시뮬레이션은 GPS 실측과 구분한다. 실제 Android 단말의 GNSS·배터리·권한 처리 검증은 출시 전 별도 필요하다.

## 실패·복원

- 서버 미실행 / HTTP 404 / 60초 타임아웃 → 오류, 준비 완료 아님.
- 다운로드 도중 취소·앱 종료 → 완성된 파일만 재시작 후 인정.
- 고정 SHA 불일치 / 잘못된 XML / 좌표 누락·범위 오류 → 저장하지 않음.
- 저장 공간 부족 → 저장 실패, 완료 상태 아님.
- 파일 손상 → 복원 오류 안내, ‘손상 파일 초기화’ 후 재다운로드 가능.
- GPX 다중 구간 사이에 가짜 직선이 생기지 않아야 함.

지도 원본은 실제 OSM, GPX는 합성 샘플이다. 이 검증은 경로의 통행 가능성이나 보행 안전성을 검수하는 절차가 아니다.

## 전국 온라인 지도

- 저장 데이터가 있으면 앱 재실행 시 저장 지도로 시작하는지 확인한다.
- 전국 지도 선택 → 제주/서울/부산 탐색 → 내 위치로 이동. 데이터가 없는 첫 설치에서도 위치 표시를 확인한다.
- 온라인 사용 중 통신 차단: 캐시만 보고 전국이 저장됐다고 판단하지 않는다. 저장 지역 버튼으로 로컬 지도를 연다. 로딩 실패 시 재시도 안내 확인.
- 권한 거부/오래된 위치에서는 현재 좌표로 오인하지 않도록 안내와 회색 점을 확인한다.
